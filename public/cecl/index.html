the identity

What LGD × ΣT ST·PDT·EADT requires

This repo assembles a first-principles CECL reserve — PD as a discrete-time hazard, survival as a competing-risk product, EAD as a rate, LGD from a marginal recovery curve — into one identity everything else has to stay consistent with.

It chooses logistic/hazard regression over a black-box ranker on purpose: a number that gets multiplied into a dollar reserve has to be a probability a reviewer can defend, not just a score that ranks well. The sibling fraud-strategy-model repo makes the opposite choice, for the same reason — different tail, different requirement.

reference

Every stage, in build order

Phase C0 — data foundation

Everything downstream depends on this panel being right — competing-risk structure has to hold by construction, not by assumption.

Loan-month panel
One row per loan per month-on-book — FICO, utilization, vintage, and a time-varying macro covariate, generated with documented true hazard rates so the fit can be checked against a known answer.
Competing exits
Default, prepay, and attrition as three mutually-exclusive flags per row — never more than one true per loan-month, by construction.

Phase C1 — survival & PD

The hazard has to earn its keep against the simplest possible baseline before it earns any covariates.

Kaplan-Meier baseline
Covariate-free life-table hazard by months-on-book × segment — the number a covariate-laden hazard model must reproduce when every covariate is switched off.
Discrete-time hazard
Bernoulli rows, one per account-month, fit via IRLS with horizon- and segment-varying coefficients — canonical-link logistic regression, not a black-box classifier.
Competing-risk survival
S_T as a product across all three exit hazards — dropping prepayment collapses this into a single-decrement model that overstates EL on exactly the fast-payoff, high-FICO segments.

Phase C2 — loss components & assembly

EAD and LGD are computed independently, then everything converges in the one file everything else has to match.

EAD as a rate
Exposure over current balance, strictly bounded — never a dollar figure. A function that returns dollars for EAD is treated as a bug, not a variant.
LGD recovery curve
Marginal, post-charge-off recoveries, discounted at an effective rate and net of collection costs, tail-extrapolated for cohorts that haven't finished recovering.
Risk-factor clustering
Hierarchical clustering on prescreened candidates, one representative feature kept per cluster — the dendrogram is the audit trail for why a feature was dropped.
The identity
LGD × ΣT S_T·PD_T·EAD_T, assembled per scenario. Every other file's output has to be consistent with what identity.py expects.

Phase C3 — scenario & reserve

The reserve isn't one number — it's three scenarios and a documented weighting.

Macro paths
Baseline, downside, and stagflation, each reverting beyond the reasonable-and-supportable window — used twice: once as a hazard covariate, once as the scenario axis for weighting.
Reserve waterfall
Baseline EL → downside/stagflation deltas → weighted reserve, charted scenario by scenario — never collapsed straight to one blended number with no bridge shown.

Phase C4 — documentation & validation

What's tested is what's claimed — nothing in the README that isn't backed by a green check here.

METHODOLOGY.md
The T11 derivation in full — Bernoulli log-loss, canonical logit link, IRLS as re-weighted least squares, and the proper-scoring-rule argument for why log-loss is the right objective for a probability that feeds a dollar reserve.
Workbook bridge
The unit-economics workbook, genericized and reconnected to this repo's identity output — breakeven CAC and contribution margin take the CECL rate from identity.py, not a second loss model.
Test suite
Three tests, three claims: competing-risk mechanics hold, EAD is always a rate, and scenario ordering is monotonic. CI fails the build if any one breaks.
